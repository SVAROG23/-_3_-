## Описание выполненной работы

В ходе выполнения задания был проведен базовый анализ данных с использованием библиотек Pandas и Matplotlib, а также реализован интерактивный дашборд на базе Streamlit (как было предложено на 5 лекции).

### 1. Загрузка данных
С помощью функции pd.read_csv() был загружен файл train.csv. 
В результате проверки установлено, что датасет содержит 891 строку и 12 столбцов. Выведены первые 3 строки для визуального контроля. Данные загружены без ошибок.

### 2. Фильтрация
Была выполнена фильтрация пассажиров по признаку выживания (колонка Survived). Оставлены только те пассажиры, которые выжили (значение 1).
*   Строк до фильтрации: 891
*   Строк после фильтрации (выжившие): 342

### 3. Расчет среднего значения
С помощью метода .mean() было рассчитано среднее значение возраста пассажиров по колонке Age.
*   **Средний возраст пассажира составил: 30 лет** (округленное значение).

### 4. Визуализация
С помощью библиотеки matplotlib была построена гистограмма распределения возраста пассажиров (plt.hist). 
На графике видно, что основная масса пассажиров (пик гистограммы) находилась в возрасте от 20 до 35 лет. Также наблюдается значительное количество маленьких детей (столбик в районе 0-5 лет) и длинный "хвост" пожилых людей вплоть до 80 лет. График наглядно подтверждает рассчитанное среднее значение.

## Опциональное задание: Интерактивный дашборд (Streamlit)

Для реализации опционального задания был разработан дашборд на базе библиотеки Streamlit. 
Интерфейс позволяет:
1. Загружать любой CSV-файл через веб-браузер.
2. Просматривать предпросмотр данных (первые 5 строк).
3. Выбирать нужную числовую колонку из выпадающего списка.
4. Строить интерактивный график распределения и автоматически рассчитывать среднее значение для выбранной колонки.

**Как запустить дашборд:**
1. Установить библиотеку: pip install streamlit
2. В терминале (находясь в папке с проектом) выполнить команду:
   python -m streamlit run дз3.py
